# VOD Recorder

치지직·유튜브·씨미(ci.me)의 실시간 방송을 녹화하고, 다시보기·클립·영상을 내려받는 자가 호스팅 도구입니다. 서버에 띄워 두고 웹 화면으로 씁니다.

> **쓰기 전에 [주의사항](docs/CAUTIONS.md)을 먼저 읽어 주십시오.** 플랫폼의 약관, 계정 제재 가능성, 저작권에 관한 내용입니다. 이 도구를 써서 생기는 책임은 쓰는 사람에게 있습니다.

## 할 수 있는 일

| 기능 | 치지직 | 유튜브 | 씨미 |
|---|---|---|---|
| 실시간 방송 자동 녹화 | ○ | ○ | ○ |
| 방송 앞부분 되감아 받기(타임머신) | ○ (최대 1시간) | — | — |
| 다시보기·영상을 주소로 받기 | ○ | ○ | ○ |
| 클립을 주소로 받기 | ○ | — | ○ |
| 채널의 다시보기 목록에서 골라 받기 | ○ | — | ○ |

- **자동 녹화**: 등록한 채널을 주기적으로 확인하다가 방송이 시작되면 녹화하고, 끝나면 파일 형식을 정리합니다(재인코딩 없음).
- **다운로드 대기열**: 일시정지와 이어받기, 다운로드 허용 시간대, 실시간 녹화 중에는 다운로드를 멈추는 기능이 있습니다.
- **파일 관리자**: 녹화 폴더 안에서 탐색, 이름 바꾸기, 이동, 삭제, 내려받기를 합니다.
- **텔레그램 알림**: 녹화 시작·종료, 실패, 디스크 부족, 쿠키 만료를 알립니다.
- **로그 보기**: 서버 로그를 화면에서 텍스트로 보고 수준·채널·글자로 거릅니다. 비밀 값은 가려서 보입니다.
- **접근 키와 API**: 다른 프로그램에서 채널과 다운로드를 다룰 수 있습니다.
- **요청 속도 조절**: 플랫폼별 확인 주기와 채널 사이 간격을 정하고, 요청 제한을 받으면 그 플랫폼만 잠시 멈춥니다.

유튜브와 씨미는 처음에 꺼져 있습니다. 설정 화면에서 안내를 읽고 동의해야 켜집니다.

SOOP은 지원하지 않습니다. 까닭은 [주의사항](docs/CAUTIONS.md#지원하지-않는-것)에 있습니다.

## 빠른 시작 (컨테이너)

```sh
docker run -d --name vodrecorder -p 127.0.0.1:8080:8080 \
  -v "$PWD/data:/data" -v "$PWD/logs:/logs" -v /srv/recordings:/recordings \
  --stop-timeout 60 ghcr.io/pcbis/vodrecorder:latest
docker logs vodrecorder   # 첫 설정 코드가 찍힙니다
```

이미지는 판마다 `ghcr.io/pcbis/vodrecorder:<판>`(예: `0.1.0`)으로도 올라갑니다. x86_64와 arm64를 함께 제공합니다.

이미지를 직접 빌드하려면 저장소를 받아 `docker build -t vodrecorder .`을 실행합니다.

브라우저로 `http://127.0.0.1:8080`을 열고, 첫 설정 화면에 로그의 코드를 넣어 관리자 계정을 만듭니다. 그다음은 [사용 설명서](docs/MANUAL.md)를 따라 채널을 등록합니다.

도커 없이 리눅스나 macOS에 직접 설치하는 방법, ARM 빌드, 서비스 등록은 [설치 안내](docs/INSTALL.md)에 있습니다.

## 필요한 것

- 컨테이너로 쓸 때: Docker 또는 Podman
- 직접 설치할 때: 파이썬 3.13 이상, FFmpeg(ffmpeg와 ffprobe)
- 녹화 파일을 둘 디스크. 1080p 60프레임 방송은 시간당 4GB 가까이 씁니다(치지직 기준 실측 약 3.7GB)
- 윈도우는 직접 지원하지 않습니다. WSL이나 Docker로 씁니다

## 문제를 알릴 때

설정 화면의 "로그 내려받기"로 만든 묶음을 이슈에 붙여 주시면 원인을 찾기 쉽습니다. 붙이기 전에 [무엇이 들어가는지](docs/LOG-EXPORT.md)를 확인해 주십시오. 공개된 곳에 올리면 채널 이름과 방송 제목이 누구에게나 보입니다.

## 만든 방식

이 프로젝트의 코드와 문서는 Anthropic의 AI인 Claude가 작성했습니다. 무엇을 만들지 정하고, 결정을 내리고, 실제 서버에서 돌려 확인하는 일은 저장소 주인(사람)이 했습니다. 다운로드 대기열과 클립 분석 등 일부는 저장소 주인이 앞서 다른 AI 도구로 만든 코드에서 옮겼습니다.

사람이 한 줄씩 검토한 코드가 아닙니다. 자동 시험과 실제 운영으로 확인했지만, 쓰기 전에 이 점을 감안해 주십시오.
